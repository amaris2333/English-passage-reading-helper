## 二、已实现的功能

| 需求 | 实现情况 |
|---|---|
| ① 导入 | 粘贴文本 ✅ ／ 上传 PDF ✅（pdf.js 本地解析、双栏自动判栏、页眉页脚剔除、**导入前可手动修正分段**）／ URL 导入 ❌ 按你的要求移除 |
| ② 双语对照 | 三档：全英文 / 中英对照 / 仅中文。**以句子为单位**，切换保持滚动位置 |

| ④ 句子点击讲解 | 每句前有三角 ▶；点击后**其余段落 `display:none` 隐藏**、本段其他句淡化，段落下方展开「句型分析（主谓宾拆解，英文原句同步高亮成分）+ 重点短语」；再点/Esc 收起并**原地复原滚动位置** |
| ⑤ 单词卡 | 左键单词弹出：音标 + 🔊 发音 + 中文释义 + 四六级/考研/雅思/托福/GRE 标签 + 同义词 + 原句语境 |
| ⑥ 便签 | 可拖动、可缩放、纯文本编辑、自动保存、一键存本地 .txt（UTF-8 BOM，中文不乱码） |
| ⑦ AI 问答 | **未做**（按你的要求） |
| ⑧ 编辑模式画笔 | 开关式；红/黑/蓝三色 + 橡皮 + 粗细调节 + 撤销/清空；**关闭只隐藏（`visibility:hidden`）不销毁，重开完整复原** |
| ⑨ 导出 PDF | 可选「仅英文/双语/仅中文」×「含笔迹 / 含句析 / 含短语 / 含便签」；走浏览器打印，产出**矢量可搜索**的 A4 PDF |

## 六、技术上的几个务实调整（与论证报告的差异）

| 报告建议 | 实际采用 | 原因 |
|---|---|---|
| Tailwind + Radix | **手写原生 CSS** | 本项目 90% 是定制排版，组件库反成负担；同时减少构建依赖与配置风险 |
| react-rnd（便签拖拽缩放） | **手写** | 需求简单，省一个依赖 |
| @floating-ui（单词卡定位） | **手写边界翻转** | 同上 |
| ECDICT 全量词库 | **内置 530 条精选词表** | ECDICT 需下载外部数据；当前精选词表覆盖外刊/学术高频词，后续可一键换成更大词库 |
| AI 批量生成译文/句析 | **未接 LLM** | 你暂时不需要 AI；界面已支持逐句手工编辑译文 |

其余关键设计**完全遵循论证结论**：句子边界在数据层、IndexedDB 存储、笔迹存结构化归一化坐标而非 PNG、`window.print()` 导出而非截图、展开/收起原地复原。
