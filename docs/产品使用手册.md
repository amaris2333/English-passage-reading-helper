## 一、这是一个什么网页

这是一个**英语外刊精读工具**。它把一篇英文文章拆解到「句子」和「单词」两个层级，让你可以：

- **逐句**查看句型结构（主谓宾拆解）、重点词组与地道表达；
- **逐词**查看音标、发音、中文释义、考试难度分级（高考 / 四六级 / 考研 / 雅思 / 托福 / GRE）与同义替换；
- 在**不离开文章**的前提下完成自译、批注、收藏、复习、测验与导出，把一篇外刊「吃透」。

它与普通翻译软件的区别在于：**它不替你读，而是帮你自己读**。所有辅助信息都可以按需展开、按需隐藏，最终目的是让你在最小的干扰下读懂原文。

它是一个**纯前端网页**：所有数据（文章、笔记、收藏、笔迹、便签）都保存在你自己电脑的浏览器里，不上传任何服务器，也不需要注册账号。

---

## 二、三步上手

1. **打开网页**，左栏会列出内置的**五篇范例文章**（全部取自公共领域或开放许可来源，刊名出处可在文章页查看）。
2. **点一篇文章**，中间阅读区即载入正文；每句前有一个 ▶ 三角，点它就能展开这句的讲解。
3. **遇到生词就点它**，会弹出单词卡：音标、发音、释义、考试难度、同义替换、例句。

到这里你已经能用它读文章了。下面是全部功能的详细说明。

## 四、功能详解

### 4.1 选择文章（左栏）

左栏从上到下依次是：

- **搜索框**：按**标题、中文标题或来源**关键字过滤（提示文案为「搜索标题或来源…」）。
- **主题标签**：点一个标签即筛选，再点取消。**可以多选——多选之间是「或」的关系**（命中任意一个标签的文章都会显示）。
  当前标签共 **9 个**：人工智能、生物医药、环境气候、商业经济、科技互联网、心理与社会、文化教育、国际政治、**能源材料**。
  文章自带的标签会**自动汇入**标签区，所以你自己导入文章带的标签也会出现在这里。
- **难度**：四档筛选——**入门**（难度 1~2）/ **进阶**（难度 3）/ **挑战**（难度 4）/ **高阶**（难度 5）。
- **文章列表**：标题为「文章（N）」，N 是**当前筛选后**的文章数量。每张卡片显示：标题、中文标题（若有）、难度徽章、**词数**、标签（多个标签用 ` / ` 连接，无标签显示「未分类」）。
  当前正在阅读的文章会有高亮标记；**你自己导入的文章**鼠标悬停时会出现「删除」按钮（内置范例文章不显示删除）。
- 底部固定按钮 **「+ 导入新文章」**。

**关于自定义标签**：点标签区的「**管理标签**」（按钮会变成「完成」），此时**只有自定义标签**上会出现 ×，点它可删除。删除前会确认：「删除自定义标签「X」？它也会从所有文章上移除。」内置的 9 个主题标签不可删除。
标签区下方的输入框（提示为「新建自定义标签…」）配合「添加」按钮可以新建标签——例如你想按「考研真题」「我的弱项」来归类，建一个就行。

### 4.2 导入自己的文章

点顶栏「导入」，弹窗里有两个标签页：

**① 粘贴文本**
把英文正文粘进文本框（提示为「在此粘贴外刊正文…」，下方实时显示「约 N 词」）。**空行分段**——系统按空行判断段落。

**② 上传 PDF**
选择本地 PDF 文件。**解析完全在你的浏览器内完成，文件不会上传**。网页会自动抽取文本、识别双栏排版、剔除页眉页脚。

**PDF 解析过程中**会显示进度：

> 正在解析 PDF 第 3/12 页 · 已用 8 秒
> 大文件可能需要 1~2 分钟，请耐心等待，期间请不要关闭页面。

（读不出总页数时显示「正在解析 PDF…」）

**解析完成后进入分段检查页**，请**核对段落是否被正确切分**——如果双栏识别有误，可直接在文本框里手动修正。页面会提示：

> 请检查分段是否正确（空行 = 一个段落）。系统已自动识别标签：X / Y，难度：N（可在导入后调整）

底部显示「预计 N 词 · 可选标签：…」。填好标题后点「**保存并开始精读**」。

**③ 导入后的两件事（重要）**

保存之后有**两个后台任务**会在阅读区顶部以提示条的形式告诉你进度：

1. **句子分析**：导入的文章默认只有第一句有句型分析，其余句子会显示提示条——
   > 本文共 58 句，已分析 1 句，还有 57 句待生成。

   点提示条上的「**生成整篇句子分析**」即可补齐（生成中按钮会变成「正在生成…」）。这是有意设计的：先让你看到效果，再决定要不要花时间分析全篇。
2. **中文译文**：导入后网页会**自动逐句生成中文译文**（异步进行，不阻塞你阅读）——
   > 正在生成中文译文 12/58 · 可先阅读，生成完会自动出现

   生成完毕提示条自动消失。若失败，会显示「**译文生成失败，**」并给出「**点击重试**」按钮。

   > **译文不会覆盖你自己写的内容**：只填充**原本为空**的译文，你手填过的译文保持不动。

### 4.3 双语对照（三档）

顶栏中间的三档开关控制整篇的显示方式（默认为**中英对照**）：

| 档位 | 效果 |
|---|---|
| 全英文 | 只显示英文原句，适合第一遍盲读 |
| 中英对照 | 每句英文下方跟一行中文译文，逐句对照 |
| 仅中文 | 只显示译文，适合读完后自测 |

**对照的最小单位是句子**，不是段落——你能一眼看出哪句对应哪句。切换时不会丢失当前展开的讲解面板、笔迹或滚动位置。

### 4.4 句子精读（本产品核心）

每个英文句子**左侧**有一个 ▶ 三角（悬停会提示「展开讲解：句型拆解 + 词组表达」）。点击后进入**聚焦模式**：

1. 除该句所在段落外的**其他段落全部隐藏**（是整体不显示，不是变灰）；同一段落内的其他句子会**变暗**，注意力完全集中在这句上；
2. 该句下方展开一个三模块面板（见下）；
3. 句中的**主谓宾等成分**用不同底色标出，与下方拆解一一对应；
4. 再点一次三角（或按 **Esc**）即收起，页面**回到你点击前的位置**（会自动补偿滚动位置，不会跳走）。

**面板的三个模块：**

**① 我的翻译** —— 一个空白输入框，提示语是：
> 先别看参考译文 —— 自己试着翻译这句话，写在这里。学完后再回来对照，检验掌握程度。

内容**自动保存**（停止输入约半秒后写入）。下方三个按钮：**「对照参考译文」**（点击展开该句的参考译文；若该句暂无译文会显示「（本文暂无参考译文）」）、**「☆ 收藏此句」**、**「收起」**。

**② 句型分析 · 五步拆解** —— 这是本产品的招牌功能，把长难句拆成五个步骤：

| 步骤 | 名称 | 你会看到什么 |
|---|---|---|
| ① | **数谓语动词** | 标出「N 件事」，逐个列出动词，并标注它是**谓语**还是干扰项（不定式 / 分词 / 介词 / 连词），干扰项附中文说明 |
| ② | **找断点** | 标出「N 处」断点位置，每处给出标记（如「逗号 + if」）与理由 |
| ③ | **定主句** | 标出「N 段」，逐段给出类型（主句 / 条件状语从句 / 定语从句…）与翻译提示，**主句高亮** |
| ④ | **拆修饰** | 列出平行结构与修饰成分 |
| ⑤ | **翻译路径** | 给出按顺序的翻译步骤 |

若某句没有预置的五步数据，面板会退回显示基础的句型、主干与成分拆解。

**③ 词组与地道表达** —— 该句中命中的词组，每条标注类别（短语动词 / 固定搭配 / 习语 / 介词框架）与中文释义。

> 并非每句都有词组标注——只有符合收录标准的才会列出，**不强行凑数**。面板会明确说明这一点。

### 4.5 单词卡

鼠标左键单击任意英文单词，弹出单词卡，包含：

- **单词**、**音标**（形如 `/ˈkwɒntəm/`）、🔊 **朗读**按钮；
- **美 / 英** 切换按钮：显示当前口音，单击即在美音与英音之间切换（默认美音）；
- **释义**（按词性分组）；
- **难度分级**：中考 / 高考 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE 等标签，帮助你判断这个词值不值得背；
- **同义替换**：3~5 个近义词；
- **原形**：当该词的表面形式与词典词条不同时（如变形词）会显示；
- **例句**：来自 Tatoeba 语料库的**其他**句子（非本文）；若没查到例句，则显示英文释义。

卡片底部会标明词条数量与例句来源。

几点说明：

- 单击单词与点击三角**互不干扰**——点词弹卡，点三角展开句子讲解；
- **专有名词**（人名 / 地名 / 机构名）本地词典不会收录，卡片会直接说明：「这看起来是专有名词（人名 / 地名 / 机构名等），词典一般不会收录，也不影响理解。」
- 词典未收录的普通生词，会**自动联网查询基础释义**（最长约 4 秒），查到即显示；查不到会提示「网络释义也未查到。可点 🔊 听发音，或记录到便签。」
- 关闭方式：点右上角 ✕，或按 **Esc**，或点击卡片以外的区域。

### 4.6 收藏夹（星标）

两处可以打星标：

- **句子**：鼠标悬停在句子上，右侧会出现 ☆，点击变 ★ 即已收藏；讲解面板里也有「☆ 收藏此句」；
- **单词**：单词卡顶部有 ☆。

顶栏「收藏夹」按钮（有收藏时会显示数量角标）打开收藏夹，内部分**两个独立的大类**（标签页显示为「句子收藏（N）」「单词收藏（N）」）：

- **句子收藏**：列出你收藏的句子（原文 + 参考译文 + 来源文章）；
- **单词收藏**：列出你收藏的单词（单词 + 释义 + 来源文章）。

收藏夹内可以：

- **新建收藏夹**并自主命名（例如「雅思长难句」「写作好句」「生词本」）；
- **重命名**（✎）/ **删除**（✕，会连同其中条目一起删除）收藏夹；
- 把条目**移动到其他收藏夹**（下拉选择）；
- **移除**单条（🗑）；
- **点击条目的来源文章名**，直接跳回原文对应位置。

句子与单词分属两个大类，不会混淆。

### 4.7 闪卡复习

把你收藏的句子和单词变成**间隔重复卡片**，帮你在快忘的时候刚好复习。

顶栏「**闪卡**」按钮打开复习界面（**有到期卡片时会显示数量**）。

- **正面**显示卡片类型（单词 / 句子）与内容；按**空格键**即可翻面；
- **背面**显示释义或参考译文，以及它来自哪篇文章；
- 翻面后给三个评级按钮：

| 按钮 | 含义 | 效果 |
|---|---|---|
| **🤔 忘记 1** | 完全没想起来 | 间隔重置，**当天再来** |
| **😐 模糊 2** | 想起来了但不熟 | 间隔**保持不变** |
| **😎 记住了 3** | 轻松想起来 | 间隔**升一档** |

**间隔档位（越往后越长）**：

```
第 0 档 → 当天       第 1 档 → 1 天      第 2 档 → 2 天
第 3 档 → 4 天       第 4 档 → 7 天      第 5 档 → 15 天
第 6 档 → 30 天（封顶）
```

如果当前**没有到期卡片、但卡片库里有卡**，会进入「**提前复习**」模式，让你主动加练。完全没有卡片时会提示：「还没有可复习的卡片。」

> 想攒更多卡片，就去文章里多点几个 ☆。

### 4.8 小测

顶栏「**小测**」按钮，针对**当前打开的这篇文章**自动出一份测验。

- **共 10 题**，按五个维度配比：

| 维度 | 题量 | 考什么 |
|---|---|---|
| 词汇 | 3 题 | 同义替换 / 释义选择 / 拼写纠错 |
| 语法 | 2 题 | 谓语动词数量、哪个是谓语动词（取自五步法数据） |
| 篇章 | 2 题 | 逻辑连接词（however / therefore / but / because） |
| 理解 | 2 题 | 判断陈述与译文是否一致（正确 / 错误 / 未提及） |
| 翻译 | 1 题 | 英→中选译文 |

- 每题**选完立刻显示正误与解析**，点「下一题」继续；
- 结束后显示**得分**（N / 10）、**分维度正确率**和**错题回顾**（含你的答案、正确答案、解析）；全部答对会显示「全部答对，太棒了！🎉」；
- 可点「**再测一次**」重新生成一份（每次题目都会变）。

**几点必须知道：**

- **首次使用需要联网加载词典**（会显示「正在准备测验…（首次使用需联网加载词典，请稍候）」）。
- **题目是实时生成的，不是预置题库**。所以**你导入的 PDF 一样能出题**。
- 但**出题依赖你文章里的数据**：
  - 「语法题」需要该句的**五步法**已生成；
  - 「理解题」「翻译题」需要该句的**中文参考译文**已生成；
  - 「词汇题」会自动**排除太简单的词**（中考 / 高考 / 四级词），优先出进阶词（六级 / 考研 / 雅思 / 托福 / GRE）。
- 某个维度数据不足时，它会**减少该维度的题量而不是乱出题**。如果什么都凑不出来，会显示「暂无可用的测验题目。」并提供「重试」按钮。
  → 导入 PDF 后**建议先等译文生成完**再点小测，否则理解题和翻译题会缺。

### 4.9 编辑模式（画笔 / 橡皮 / 荧光笔）

点顶栏「编辑模式」开启（按钮会变成「编辑中」），出现浮动工具条：

| 工具 | 说明 |
|---|---|
| **画笔** | 红 / 黑 / 蓝三色，在文章上自由书写 |
| **橡皮** | 擦除笔迹 |
| **粗细** | 笔宽 **1~24 px** 可调（画笔与橡皮共用） |
| **荧光笔** | 三色（浅黄 / 浅蓝 / 浅紫）；**按住左键拖动**选中一个词或一句话即可标记重点；**单击**已有标记可将其擦除 |
| **撤销笔迹** | 撤回上一笔 |
| **清空笔迹** | 清除全部手写 |
| **清空荧光笔** | 清除全部荧光标记 |
| **退出编辑** | 关闭工具条 |

**关闭编辑模式后：笔迹与荧光标记仍然显示，并未删除**。切换文章时，每篇文章的笔迹与荧光标记各自独立保存。

> 笔迹和荧光标记会随文章内容一起滚动，**不会错位**。它们也会在导出 PDF 时按你的选择一并输出。

### 4.10 便签

顶栏「便签」按钮打开一个可拖动、可缩放的便签窗：

- **拖动**：按住便签顶部标题栏；
- **缩放**：拖动右下角；
- **纯文本**：粘贴时自动去除富文本格式；
- **⭳ 保存到本地 txt**：导出为 `.txt` 文件（**UTF-8 带 BOM 编码，中文不乱码**），文件名形如 `外刊精读笔记_20260920_1735.txt`；
- **⌫ 清空**、**✕ 关闭**（关闭只是隐藏，内容仍在）。

便签适合随手记短语、疑问、写作素材，内容**自动保存**。

### 4.11 导出 PDF

顶栏「导出 PDF」打开配置面板，可勾选：

- **内容语言**：仅英文 / 双语对照 / 仅中文；
- **包含我的手写批注**（画笔笔迹）；
- **包含已展开句子的句法分析**；
- **包含重点短语**；
- **在文末附上便签内容**。

点「导出」后浏览器会弹出**打印窗口**，请在「目标打印机 / 目的地」中选择 **另存为 PDF**。这样导出的 PDF 是矢量的，文字可选中、可搜索。

### 4.12 设置与数据备份

顶栏「设置」打开设置面板：

- **朗读语速**：0.5 ~ 1.4 倍速可调（默认 0.9），影响单词卡里的 🔊 发音；
- **在讲解面板中显示重点短语**：控制在讲解面板中是否显示词组模块；
- **备份全部数据**：导出一个 JSON 文件（包含全部文章、笔记、收藏、笔迹、便签），文件名形如 `外刊精读备份_2026-09-20.json`；
- **恢复备份**：从 JSON 文件还原（会提示恢复了多少篇并自动刷新）；
- **清空所有数据**：慎用，确认后清空本机所有文章、笔迹与便签，建议先备份；
- **数据与授权**：列明本网页使用的开源数据来源与授权（详见第七章）。

> **强烈建议定期备份。** 所有数据都在浏览器本地，如果清除浏览器数据，笔记会随之丢失。

## 五、推荐的精读流程

上面是功能清单，下面是怎么把它们串成一个**有效的学习闭环**。以一篇 1,500 词的外刊为例：

**第一遍 · 盲读（约 8 分钟）**
顶栏切到「全英文」。不通读、不查词，只求抓住文章主旨与结构。读完合上，用一句话概括这篇文章在讲什么。

**第二遍 · 逐句精读（约 30~40 分钟）**
切到「中英对照」。**先别看参考译文**——从第一句开始：

1. 自己在心里（或写进「我的翻译」框）翻译这句话；
2. 点句子前的 ▶，对照「句型分析」看主干和从句拆解，检查你的理解是否一致；遇到长难句，**按五步法顺序走一遍**（先数谓语动词，再找断点）；
3. 点「对照参考译文」，比较你的翻译与参考译文的差距；
4. 遇到生词点单词卡，重点看**难度分级**（如果是高考/四级词就值得记，GRE 词可以放过）和**同义替换**；
5. 觉得「这句值得记住」就点句子右侧的 ☆；
6. 用荧光笔把**逻辑连接词**和**你误解过的成分**标出来。

**第三遍 · 复盘（约 10 分钟）**
回到「全英文」，通读一遍。这次你应该能顺畅读完。打开**闪卡**把到期卡片过一遍，再做一次**小测**检验掌握程度。

**沉淀**

- 用「导出 PDF」勾选「双语对照 + 我的批注 + 重点短语」，导出一份带笔记的 PDF 归档；
- 或者只勾「附上便签内容」，把便签里记的生词和好句导出成一份复习清单。

**关于「我的翻译」框**：它是这个产品里最反直觉、但最有价值的设计。看懂和能译出来是两回事——先自译再对照，你才知道自己哪里理解错了。建议至少对**长难句**这么做。

## 六、常见问题

**Q1：点了单词没反应？**
确认点的是英文单词本身（不是标点），且不在编辑模式中。专有名词（人名等）会显示专有名词提示而非释义，这是正常行为。

**Q2：某句没有「词组与地道表达」？**
该句没有命中收录标准（短语动词 / 固定搭配 / 习语 / 介词框架），不强行凑数。面板会明确说明这一点。

**Q3：句子分析看起来不对？**
内置文章的短句和部分句子由规则引擎生成，长难句为人工校对，个别成分的判断可能有偏差。你可以在「我的翻译」框旁记录疑问。

**Q4：导入的 PDF 段落顺序乱了？**
双栏排版自动识别不是 100% 准确。在导入预览页直接编辑文本框修正即可。

**Q5：PDF 解析特别慢？**
解析过程会显示「第 x/y 页 · 已用 N 秒」，正常现象，请耐心等待、不要关闭页面。耗时主要来自 PDF 库本身逐页提取文本，文件越大越慢。

**Q6：导入的文章没有中文译文？**
译文是**后台异步生成**的，顶部提示条会显示「正在生成中文译文 x/y」。如果显示「译文生成失败」，点「点击重试」。**先等它跑完再看小测**，否则理解题和翻译题会缺。

**Q7：小测出不了题 / 题目很少？**
三个可能原因：① 词典还没加载（首次需联网下载词库）；② 文章的译文或句子分析还没生成完；③ 文章本身用词太基础，被难度过滤掉了。可以点「重试」，或先补齐分析再测。

**Q8：闪卡里没有卡片？**
闪卡用的是你**收藏的句子和单词**。先去文章里多点几个 ☆。

**Q9：导出 PDF 时中文乱码 / 内容不全？**
请在浏览器打印窗口中确认纸张为 A4、缩放为 100%，并选择「另存为 PDF」。若勾选了「包含手写批注」，请确认对应文章确实有笔迹。

**Q10：换了浏览器 / 清了缓存，文章和笔记没了？**
数据存在浏览器本地。请在原浏览器中用「设置 → 备份全部数据」导出 JSON，再在新环境中「恢复备份」。

**Q11：某句话的断句切错了？**
断句由算法完成（正确处理 U.S. / e.g. / don't 等缩写与撇号），但仍可能有极少数错误。可在编辑模式下用荧光笔把错误的切分标出来，或反馈给维护者。
