# 英语外刊精读网页 · 产品使用手册

> 版本：v1.0 ｜ 适用对象：本网页的全部使用者
> 本手册完整说明本网页的各项功能、操作方法与推荐用法。

---

## 一、这是一个什么网页

这是一个**英语外刊精读工具**。它把一篇英文文章拆解到「句子」和「单词」两个层级，让你可以：

- **逐句**查看句型结构（主谓宾拆解）、重点词组与地道表达；
- **逐词**查看音标、发音、中文释义、考试难度分级（四六级 / 考研 / 雅思 / 托福 / GRE）与同义替换；
- 在**不离开文章**的前提下完成自译、批注、收藏、导出，把一篇外刊「吃透」。

它与普通翻译软件的区别在于：**它不替你读，而是帮你自己读**。所有辅助信息都可以按需展开、按需隐藏，最终目的是让你在最小的干扰下读懂原文。

它是一个**纯前端网页**：所有数据（文章、笔记、收藏、笔迹）都保存在你自己电脑的浏览器里，不上传任何服务器，也不需要注册账号。

---

## 二、三步上手

1. **打开网页**，左侧会列出内置的范例文章（两篇公共领域素材：一篇人工智能政策分析、一篇气候科学报道）。
2. **点一篇文章**，中间阅读区即载入正文；每句前有一个 ▶ 三角，点它就能展开这句的讲解。
3. **遇到生词就点它**，会弹出单词卡：音标、发音、释义、考试难度、同义替换、例句。

到这里你已经能用它读文章了。下面是全部功能的详细说明。

## 四、功能详解

### 4.1 选择文章

左栏从上到下依次是：

- **搜索框**：按标题或来源关键字过滤。
- **主题标签**：点一个标签即筛选；再点取消。可以多选（多选之间是「或」的关系——命中任意一个即显示）。
- **难度**：入门 / 进阶 / 挑战 / 高阶，四档。
- **文章列表**：每张卡片显示标题、中文标题、难度、词数与标签。鼠标悬停在卡片上会出现「删除」按钮（仅对你自己导入的文章显示）。

**关于自定义标签**：点标签区的「管理标签」进入管理模式，此时自定义标签上会出现 ×，可将其删除（删除时会同时从所有文章上移除）。标签区下方的输入框可以新建标签——例如你想按「考研真题」「我的弱项」来归类，建一个就行。

### 4.2 导入自己的文章

点顶栏「导入」，有两种方式：

- **粘贴文本**：把英文正文粘进文本框，**空行分段**（系统按空行判断段落）。
- **上传 PDF**：选择本地 PDF 文件，网页会自动抽取文本、识别双栏排版、剔除页眉页脚。

点「下一步：检查分段」后进入预览页，请**核对段落是否被正确切分**——如果 PDF 的双栏识别有误，可直接在文本框里手动修正。填好标题后点「保存并开始精读」。

> 导入后的文章默认**只有第一句有句型分析**，其余句子会显示一条提示条。这是有意设计的：先让你看到效果，再决定要不要花时间分析全篇。点提示条上的「生成整篇句子分析」即可补齐。

### 4.3 双语对照（三档）

顶栏中间的三档开关控制整篇的显示方式：

| 档位 | 效果 |
|---|---|
| 全英文 | 只显示英文原句，适合第一遍盲读 |
| 中英对照 | 每句英文下方跟一行灰色中文译文，逐句对照 |
| 仅中文 | 只显示译文，适合读完后自测 |

**对照的最小单位是句子**，不是段落——你能一眼看出哪句对应哪句。切换时不会丢失当前展开的讲解面板、笔迹或滚动位置。

### 4.4 句子精读（本产品核心）

每个英文句子前有一个 ▶ 三角。点击后进入**聚焦模式**：

1. 除该句所在段落外的**其他段落全部隐藏**，注意力完全集中在这句上；
2. 该句下方展开一个三模块面板（见下）；
3. 该句以浅黄底色高亮，句中的**主谓宾成分**会用不同底色标出并与下方的拆解一一对应；
4. 再点一次三角（或按 Esc）即收起，页面**回到你点击前的位置**。

**面板的三个模块：**

**① 我的翻译** —— 一个空白输入框。设计意图是：**先别看参考译文**，自己试着把这句翻译出来写在这里（自动保存）。读完之后再点「对照参考译文」检查，这才是检验掌握程度的方式。

**② 句型分析** —— 包含四部分：
- **句型**：如「主谓宾 + 非限定性定语从句」
- **句子主干**：把主谓宾单独拎出来
- **主干成分**：逐个列出主语 / 谓语 / 宾语 / 表语，并在原句中用底色标出
- **从句 / 插入语·同位语 / 修饰成分**：逐层列出，每条附说明
- **点拨**：针对该句的语法要点提示

**③ 词组与地道表达** —— 该句中命中的词组，每条标注类别（短语动词 / 固定搭配 / 习语 / 介词框架）与中文释义。

> 并非每句都有词组标注——只有符合收录标准的才会列出，不强行凑数。详见 4.13 的收录标准。

### 4.5 单词卡

鼠标左键单击任意英文单词，弹出单词卡，包含：

- **音标** 与 🔊 **朗读**按钮；
- **美 / 英** 切换按钮：显示当前口音，单击即在美音与英音之间切换；
- **释义**（按词性分组）；
- **难度分级**：四级 / 六级 / 考研 / 雅思 / 托福 / GRE 等标签，帮助你判断这个词值不值得背；
- **同义替换**：3~5 个近义词；
- **例句**：来自 Tatoeba 语料库的**其他**句子（非本文），命中词用【】标出。

几点说明：

- 单击单词与点击三角**互不干扰**——点词弹卡，点三角展开句子讲解；
- **专有名词**（人名 / 地名 / 机构名）本地词典不会收录，卡片会直接说明这一点，**不影响理解**；
- 个别生词本地词典未收录时，会**自动联网查询基础释义**（最长约 4 秒），查到即显示；
- 关闭方式：点右上角 ✕，或点击卡片以外的区域，或按 Esc。

### 4.6 收藏夹（星标）

两处可以打星标：

- 句子：鼠标悬停在句子上，右侧出现 ☆，点击变 ★ 即已收藏；
- 单词：单词卡顶部有 ☆。

顶栏「收藏夹」按钮打开收藏夹，内部分**两个独立的大类**：

- **句子收藏**：列出你收藏的句子（原文 + 参考译文 + 来源文章）；
- **单词收藏**：列出你收藏的单词（单词 + 释义 + 来源文章）。

收藏夹内可以：

- **新建收藏夹**并自主命名（例如「雅思长难句」「写作好句」「生词本」）；
- **重命名 / 删除**收藏夹（删除会连同其中条目一起删除）；
- **移动**条目到其他收藏夹；
- **点击条目的来源文章名**直接跳回原文对应位置。

句子与单词分属两个大类，不会混淆。

### 4.7 编辑模式（画笔 / 橡皮 / 荧光笔）

点顶栏「编辑模式」开启，出现浮动工具条：

- **画笔**：红 / 黑 / 蓝三色，笔宽 1~24px 可调，在文章上自由书写；
- **橡皮**：擦除笔迹，粗细可调；
- **荧光笔**：三色（浅黄 / 浅蓝 / 浅紫），**按住左键拖动**选中一个词或一句话即可标记重点；**单击**已有标记可将其擦除；
- **撤销笔迹 / 清空笔迹 / 清空荧光笔**。

**关闭编辑模式（再点一次按钮）后：笔迹与荧光标记只是被隐藏，并未删除**——再次开启编辑模式时会原样恢复。切换文章时，每篇文章的笔迹与荧光标记各自独立保存。

> 笔迹和荧光标记会随文章内容一起滚动，不会错位。它们也会在导出 PDF 时按你的选择一并输出。

### 4.8 便签

顶栏「便签」按钮打开一个可拖动、可缩放的便签窗：

- **拖动**：按住便签顶部标题栏；
- **缩放**：拖动右下角；
- **纯文本**：粘贴时自动去除富文本格式；
- **⭳ 保存到本地**：导出为 `.txt` 文件（UTF-8 编码，中文不乱码）；
- **⌫ 清空**、**✕ 关闭**（关闭只是隐藏，内容仍在）。

便签适合随手记短语、疑问、写作素材，内容自动保存。

### 4.9 导出 PDF

顶栏「导出 PDF」打开配置面板，可勾选：

- **内容语言**：仅英文 / 双语对照 / 仅中文；
- **包含我的手写批注**（画笔笔迹）；
- **包含已展开句子的句法分析**；
- **包含重点短语**；
- **在文末附上便签内容**。

点「导出」后浏览器会弹出打印窗口，请在「目标打印机 / 目的地」中选择 **另存为 PDF**。这样导出的 PDF 是矢量的，文字可选中、可搜索。

### 4.10 设置与数据备份

顶栏「设置」打开设置面板：

- **朗读语速**：0.5~1.4 倍速可调；
- **显示重点短语**：控制在讲解面板中是否显示词组；
- **备份全部数据**：导出一个 JSON 文件（包含全部文章、笔记、收藏、笔迹、便签）；
- **恢复备份**：从 JSON 文件还原；
- **清空所有数据**：慎用，建议先备份；
- **数据与授权**：列明本网页使用的开源数据来源与授权。

> **强烈建议定期备份。** 所有数据都在浏览器本地（IndexedDB），如果清除浏览器数据，笔记会随之丢失。

## 五、推荐的精读流程

上面是功能清单，下面是怎么把它们串成一个**有效的学习闭环**。以一篇 1,500 词的外刊为例：

**第一遍 · 盲读（约 8 分钟）**
顶栏切到「全英文」。不通读、不查词，只求抓住文章主旨与结构。读完合上，用一句话概括这篇文章在讲什么。

**第二遍 · 逐句精读（约 30~40 分钟）**
切到「中英对照」。**先别看参考译文**——从第一句开始：

1. 自己在心里（或写进「我的翻译」框）翻译这句话；
2. 点句子前的 ▶，对照「句型分析」看主干和从句拆解，检查你的理解是否一致；
3. 点「对照参考译文」，比较你的翻译与参考译文的差距；
4. 遇到生词点单词卡，重点看**难度分级**（如果是高考/四级词就值得记，GRE 词可以放过）和**同义替换**；
5. 觉得「这句值得记住」就点句子右侧的 ☆；
6. 觉得「这个搭配很地道」也记下来；
7. 用荧光笔把**逻辑连接词**和**你误解过的成分**标出来。

**第三遍 · 复盘（约 10 分钟）**
回到「全英文」，通读一遍。这次你应该能顺畅读完。打开收藏夹，把今天收藏的句子和单词过一遍。

**沉淀**
- 用「导出 PDF」勾选「双语对照 + 我的批注 + 重点短语」，导出一份带笔记的 PDF 归档；
- 或者只勾「附上便签内容」，把便签里记的生词和好句导出成一份复习清单。

**关于「我的翻译」框**：它是这个产品里最反直觉、但最有价值的设计。看懂和能译出来是两回事——先自译再对照，你才知道自己哪里理解错了。建议至少对**长难句**这么做。

## 六、常见问题

**Q1：点了单词没反应？**
确认点的是英文单词本身（不是标点），且不在编辑模式中。专有名词（人名等）会显示专有名词提示而非释义，这是正常行为。

**Q2：某句没有「词组与地道表达」？**
该句没有命中收录标准（短语动词 / 固定搭配 / 习语 / 介词框架），不强行凑数。面板会明确说明这一点。

**Q3：句子分析看起来不对？**
内置文章的分析中，短句和部分句子由规则引擎生成，长难句为人工校对，个别成分的判断可能有偏差。你可以在「我的翻译」框旁记录疑问。

**Q4：导入的 PDF 段落顺序乱了？**
双栏排版自动识别不是 100% 准确。在导入预览页直接编辑文本框修正即可。

**Q5：导出 PDF 时中文乱码 / 内容不全？**
请在浏览器打印窗口中确认纸张为 A4、缩放为 100%，并选择「另存为 PDF」。若勾选了「包含手写批注」，请确认对应文章确实有笔迹。

**Q6：换了浏览器 / 清了缓存，文章和笔记没了？**
数据存在浏览器本地。请在原浏览器中用「设置 → 备份全部数据」导出 JSON，再在新环境中「恢复备份」。

**Q7：某句话的断句切错了？**
断句由算法完成（正确处理 U.S. / e.g. / don't 等缩写与撇号），但仍可能有极少数错误。可在编辑模式下用荧光笔把错误的切分标出来，或反馈给维护者。
